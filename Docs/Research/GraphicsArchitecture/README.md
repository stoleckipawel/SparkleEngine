# Graphics Architecture Research

**Status:** research-family index

**Scope:** route external rendering architecture precedent, focused graphics-feature studies, and the RHI/Renderer documentation coverage model

## Choose By Design Question

| Question | Research route | Local decision remains in |
| --- | --- | --- |
| How do mature renderer repositories divide scene, graph, pipeline, and backend responsibilities? | repository comparison | Architecture module/cross-module owners |
| What must a complete Renderer/RHI feature dossier explain? | documentation coverage precedent | Documentation Organization and owning feature pages |
| How should technical pages become readable without losing exact evidence? | Unreal presentation precedent | Documentation template and indexes |
| What separates an interactive reference branch from an offline oracle? | offline path-tracer completion study | path-tracer dossier and discovery gate |
| How should debug domains/show flags or deferred decals compose? | focused debug/decal precedent | their Renderer target-architecture documents |

Research supplies precedent and options. It never promotes a local target into implemented behavior or chooses a candidate verdict.
