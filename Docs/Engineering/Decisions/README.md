# Engineering Decisions

**Status:** engineering decision index

Decision records preserve why an engineering choice was accepted. They do not override current standards or executable configuration.

## Reading Rule

Open a decision when the rationale or rejected alternatives matter. For day-to-day implementation, follow the linked current standard and repository configuration; if they disagree, reconcile the current owner instead of treating the historical ballot as executable truth.
